# Asset lisansları

Oyundaki 3D modellerin kaynağı ve lisansı. Primitive (kutu/küre) görseller Unity ile gelir; lisans gerektirmez.

## Kenney (CC0 1.0)

[Kenney](https://kenney.nl) paketleri **Creative Commons Zero (CC0 1.0)** ile dağıtılır: kişisel, eğitim ve ticari kullanım serbesttir. Kaynak göstermek zorunlu değildir; `Kenney` / [www.kenney.nl](https://www.kenney.nl) teşekkürü takdir edilir.

| Paket | Sürüm | Oyunda kullanım | Dosyalar |
|---|---|---|---|
| [Car Kit](https://kenney.nl/assets/car-kit) | 3.1 | Garaj araçları, NPC, park, hırsız | `Assets/Resources/Kenney/Vehicles/` |
| [City Kit (Suburban)](https://kenney.nl/assets/city-kit-suburban) | 2.0 | Binalar ve park ağaçları | `Assets/Resources/Kenney/City/` |

Paketteki `License.txt` kopyaları: `Assets/Resources/Kenney/CarKit-License.txt`, `CityKitSuburban-License.txt`.

Kullanılmayan Kenney parçaları (kart, enkaz, çit, yol kiti) **repoya alınmadı** — boyut küçük kalsın.

## Meshy

[Meshy](https://www.meshy.ai) ile üretilen özel araç şu an **yok**. Cloud Agent’ın Meshy hesabı / API anahtarı yok; model uydurulmadı.

Dondurma kamyonu Kenney paketinde yok: **Kenney van + primitive top (külah)** kullanılıyor. İleride Mac’te Meshy’den FBX alınıp `Assets/Resources/Vehicles/dondurma` (prefab veya import edilmiş model) konursa `KenneyLibrary` onu otomatik tercih eder.

Meshy planının ticari koşullarını eklemeden önce kontrol et; üretilen dosyayı bu tabloya ekle.

|---|---|---|
| — | — | Henüz Meshy dosyası yok |
